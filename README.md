# Мои планы — Android-приложение для планирования и напоминаний

Простое приложение на Kotlin: записать план → выбрать дату и время → в нужный момент приходит уведомление.

## Возможности

- Создание плана: название, описание, дата и время
- Список планов, отсортированный по времени
- Отметка «выполнено» и удаление
- Редактирование плана по нажатию на карточку
- Уведомление со звуком и вибрацией в заданное время (AlarmManager, точный будильник)
- Напоминания восстанавливаются после перезагрузки телефона
- Данные хранятся локально (JSON в SharedPreferences), интернет не нужен

Минимальная версия Android: 7.0 (API 24).

## Способ 1 (без установки программ): собрать APK через GitHub Actions

В проекте уже есть готовый workflow `.github/workflows/build-apk.yml`.

1. Создайте репозиторий на GitHub (или используйте свой).
2. Загрузите туда содержимое этого архива (кнопка *Add file → Upload files*, перетащите все папки).
3. Откройте вкладку **Actions** → запуск «Build APK» начнётся автоматически (или нажмите *Run workflow*).
4. Через 3–7 минут внизу страницы сборки появится артефакт **planner-apk** — скачайте его, внутри `app-debug.apk`.
5. Перекиньте APK на телефон и установите (разрешите «Установка из неизвестных источников»).

## Способ 2: Android Studio

1. Распакуйте архив и откройте папку `PlannerApp` в Android Studio (File → Open).
2. Дождитесь Gradle Sync.
3. Build → Build Bundle(s)/APK(s) → **Build APK(s)**.
4. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Способ 3: командная строка

Требуется JDK 17, Android SDK и Gradle 8.7+:

```bash
cd PlannerApp
gradle assembleDebug
```

## Важно про уведомления

При первом запуске приложение попросит:

- разрешение на уведомления (Android 13+);
- разрешение «Будильники и напоминания» (Android 12+) — без него уведомление может прийти с задержкой.

На Xiaomi/Huawei/Samsung также отключите для приложения оптимизацию батареи, иначе система может глушить фоновые напоминания.

## Структура

```
PlannerApp/
├─ app/src/main/java/com/planner/reminder/
│  ├─ MainActivity.kt        — список планов
│  ├─ EditPlanActivity.kt    — создание/редактирование
│  ├─ PlanAdapter.kt         — карточки списка
│  ├─ Plan.kt / PlanStore.kt — модель и хранилище
│  ├─ ReminderScheduler.kt   — постановка будильников
│  ├─ ReminderReceiver.kt    — показ уведомления
│  └─ BootReceiver.kt        — восстановление после перезагрузки
├─ app/src/main/res/         — экраны, тексты, иконки
└─ .github/workflows/build-apk.yml
```
