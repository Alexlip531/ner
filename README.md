# Забота рядом — WordPress тема + плагин курса валют

Репозиторий содержит WordPress-тему **«Забота рядом»** (каталог услуг по уходу за пожилыми) и WordPress-плагин **«Курс валют»** (курсы ЦБ РФ).

## 📦 Состав репозитория

```text
.
├── zabota-ryadom/                # WordPress тема «Забота рядом»
└── currency-exchange-rates/      # WordPress плагин «Курс валют ЦБ РФ»
```

---

## 🎨 Тема «Забота рядом»

Тема для каталога услуг по уходу за пожилыми: пансионаты, сиделки, уход на дому, реабилитация.

### Возможности

- 🏠 **Готовая главная страница** со всеми блоками:
  - Hero с табами (Пансионат / Сиделка / Уход на дому / Реабилитация)
  - Фильтр поиска (город + тип ухода + бюджет)
  - Социальное доказательство с аватарками
  - 4 плавающие карточки преимуществ
  - 5 карточек услуг
  - 8 иконок подбора по ситуации
  - Калькулятор стоимости с ползунком бюджета
  - Карта с фильтрами и метками пансионатов
  - Каталог 4 пансионатов с рейтингами и тегами
  - Trust-bar с 4 преимуществами
  - Полноценный футер с контактами и соцсетями
- 📱 **Полностью адаптивная** (mobile-first)
- 🎯 Кастомный логотип через Customizer
- 📝 2 меню: главное и футер
- 🌐 Готова к переводу
- ⚡ Кастомные скрипты: табы, слайдер бюджета, избранное, scroll-top
- 🎨 CSS-переменные для лёгкого перекрашивания

### Установка темы

1. Скопируйте папку `zabota-ryadom/` в `/wp-content/themes/`
2. Активируйте тему в **Внешний вид → Темы**
3. В **Настройки → Чтение** выберите «статическая страница» → «Главная»
4. Настройте меню в **Внешний вид → Меню**

## 💱 Плагин «Курс валют»

Плагин отображения актуальных курсов валют Банка России (ЦБ РФ).

### Возможности

- 🔌 Шорткод `[exchange_rates]` с 3 шаблонами: `table`, `cards`, `compact`
- 📦 Виджет «Курс валют ЦБ РФ» для сайдбара
- ⚙️ Админ-страница настроек (Settings API)
- 🌐 Бесплатный API ЦБ РФ (cbr-xml-daily.ru) — без API-ключа
- 💾 Кэш через Transients API (настраиваемый TTL)
- 🔄 Принудительное обновление курсов
- 📈 Изменение курса за день в ₽ и %, флаги стран (эмодзи)

### Использование шорткода

```text
[exchange_rates currencies="USD,EUR,GBP" layout="cards" show_flag="1" show_change="1"]
```
