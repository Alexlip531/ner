# Курс валют — WordPress Plugin

Плагин **«Курс валют»** для WordPress отображает актуальные курсы валют Банка России (ЦБ РФ).
Источник данных — публичное API [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/) (бесплатно, без API-ключа).

## Возможности

- 🔌 **Шорткод** `[exchange_rates]` для вставки в любые записи и страницы
- 📦 **Виджет** «Курс валют ЦБ РФ» для сайдбара
- 🎨 **Три варианта отображения**: таблица, карточки, компактный список
- 🌍 **Поддержка 40+ валют**: USD, EUR, GBP, CNY, JPY, CHF, BYN, KZT и др.
- 🏳️ **Флаги стран** (эмодзи) рядом с кодом валюты
- 📈 **Изменение курса** за день в абсолютных и процентных значениях
- 📅 **Дата и время** актуальности курса
- 💾 **Гибкое кэширование** через Transients API (по умолчанию — 1 час)
- 🔄 **Принудительное обновление** курсов из админки
- 📱 **Адаптивная вёрстка**, поддержка тёмной темы
- ⚡ **Без внешних зависимостей** и без API-ключей

## Установка

1. Скопируйте папку `currency-exchange-rates` в `/wp-content/plugins/`
2. Активируйте плагин в разделе **Плагины** админ-панели WordPress
3. Перейдите в **Курс валют** в боковом меню для настройки отображаемых валют
4. Используйте шорткод `[exchange_rates]` в любой записи/странице или добавьте виджет

## Использование шорткода

Базовое использование (настройки из админки):

```text
[exchange_rates]
```

С параметрами:

```text
[exchange_rates currencies="USD,EUR,GBP,CNY" layout="cards" show_flag="1" show_change="1" show_date="1"]
```

### Параметры шорткода

| Параметр      | Тип        | По умолчанию  | Описание                                              |
|---------------|------------|---------------|------------------------------------------------------|
| `currencies`  | строка     | из настроек   | Коды валют через запятую: `USD,EUR,GBP`              |
| `layout`      | строка     | `table`       | `table`, `cards` или `compact`                       |
| `show_flag`   | 1 / 0      | 1             | Показывать флаги стран                               |
| `show_change` | 1 / 0      | 1             | Показывать изменение курса за день                   |
| `show_date`   | 1 / 0      | 1             | Показывать дату актуальности курса                   |

## Архитектура

Плагин построен по принципам объектно-ориентированного кода:

- **`Currency_Exchange_Rates`** — главный класс-синглтон, инициализирует хуки
- **`CBR_API`** — статический класс для получения и кэширования курсов
- **`CER_Shortcode`** — регистрация шорткода и рендеринг шаблонов
- **`CER_Widget`** — виджет для сайдбара (наследует `WP_Widget`)
- **`CER_Admin`** — страница настроек, регистрация настроек через Settings API

### Источник данных

```text
https://www.cbr-xml-daily.ru/daily_json.js
```

API возвращает JSON с курсами всех валют ЦБ РФ. Курсы обновляются ЦБ РФ каждый рабочий день. Плагин кэширует ответ через WordPress Transients API (по умолчанию 1 час, настраивается).

## Требования

- WordPress 5.5+
- PHP 7.2+
- Расширение `cURL` (входит в стандартную поставку PHP для WordPress)
- Включённые Transients API (по умолчанию включены в WordPress)

## Кэширование

Плагин использует WordPress Transients API:

- Кэш-ключ: `cer_rates_cache`
- Время жизни: по умолчанию `HOUR_IN_SECONDS` (3600 секунд)
- Минимальное значение: 60 секунд (защита от слишком частых запросов)
- Принудительное обновление: кнопка «Обновить курсы сейчас» на странице настроек
- Автоматическая очистка кэша при сохранении настроек
