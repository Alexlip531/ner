Плагин отображения актуальных курсов валют ЦБ РФ. Шорткод [exchange_rates], виджет, страница настроек, кэширование.

== Description ==

Плагин «Курс валют» отображает актуальные курсы валют Банка России на вашем сайте WordPress.
Источник данных — публичное API https://www.cbr-xml-daily.ru/ (не требует API-ключа).

= Возможности =

* Шорткод `[exchange_rates]` для вставки в любые записи и страницы.
* Виджет «Курс валют ЦБ РФ» для сайдбара.
* Три варианта отображения: таблица, карточки, компактный список.
* Поддержка 40+ валют: USD, EUR, GBP, CNY, JPY, CHF, BYN, KZT и др.
* Флаги стран (эмодзи) рядом с кодом валюты.
* Изменение курса за день в абсолютных и процентных значениях.
* Дата и время актуальности курса.
* Гибкое кэширование (по умолчанию — 1 час).
* Принудительное обновление курсов из админки.
* Адаптивная вёрстка, поддержка тёмной темы.
* Без внешних зависимостей, без API-ключей.

= Использование шорткода =

`[exchange_rates]` — базовое использование (настройки из админки).

`[exchange_rates currencies="USD,EUR,GBP" layout="cards" show_flag="1" show_change="1" show_date="1"]`

Параметры:

* `currencies` — список кодов валют через запятую (USD,EUR,GBP,CNY).
* `layout` — `table`, `cards` или `compact`.
* `show_flag` — `1` или `0`.
* `show_change` — `1` или `0`.
* `show_date` — `1` или `0`.

= Виджет =

Внешний вид → Виджеты → перетащите «Курс валют ЦБ РФ» в нужную область. Настройте заголовок, список валют и отображаемые элементы.

== Installation ==

1. Скопируйте папку `currency-exchange-rates` в `/wp-content/plugins/`.
2. Активируйте плагин в разделе «Плагины» админ-панели WordPress.
3. Перейдите в «Курс валют» в боковом меню для настройки отображаемых валют.
4. Используйте шорткод `[exchange_rates]` в любой записи или странице, либо добавьте виджет в сайдбар.

== Frequently Asked Questions ==

= Откуда берутся курсы валют? =

Из публичного API ЦБ РФ: https://www.cbr-xml-daily.ru/daily_json.js

= Нужен ли API-ключ? =

Нет, ключ не требуется. API бесплатное и публичное.

= Как часто обновляются курсы? =

ЦБ РФ обновляет курсы ежедневно в рабочие дни. Плагин кэширует ответ API (по умолчанию 1 час), чтобы не нагружать сервер. Время кэширования настраивается.

= Можно ли использовать свой API? =

Да, разработчики могут переопределить константу `CER_API_URL` или расширить класс `CBR_API`.
