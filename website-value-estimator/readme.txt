Плагин оценки стоимости сайта. Пользователь вводит ссылку на сайт, плагин проверяет его через бесплатные сервисы (Google PageSpeed Insights, RDAP, SSL, HTML-анализ) и на основе показателей выводит расчётную стоимость сайта с детальным отчётом.

== Description ==

**Website Value Estimator** — это WordPress-плагин, который позволяет посетителям вашего сайта узнать расчётную стоимость любого другого сайта. Плагин использует только бесплатные публичные API и не требует платных подписок.

= Как это работает =

1. Пользователь вводит URL сайта в форму на вашем сайте.
2. Плагин проверяет сайт через несколько бесплатных сервисов:
   * **Google PageSpeed Insights** — performance, accessibility, best-practices, SEO scores
   * **RDAP** (современная замена WHOIS) — возраст домена, регистратор
   * **SSL-анализ** — наличие, эмитент, срок действия сертификата
   * **HTML-парсинг** — мета-теги, Open Graph, Schema.org, аналитика, реклама, соцсети
3. На основе собранных метрик рассчитывается стоимость (базовая стоимость + бонусы за хорошие показатели − штрафы за проблемы).
4. Пользователь видит подробный отчёт:
   * итоговая стоимость с категорией (низкая / средняя / высокая / очень высокая / премиум)
   * 4 круговых индикатора PageSpeed
   * Web Vitals (LCP, FCP, CLS, TBT)
   * технические характеристики (SSL, возраст, регистратор, размер, скрипты)
   * SEO и маркетинговые проверки (9 пунктов)
   * детальный расчёт — какие бонусы и штрафы сложились в итоговую сумму

= Используемые сервисы (все бесплатные) =

* Google PageSpeed Insights API (https://developers.google.com/speed/docs/insights/v5/get-started)
* RDAP (https://rdap.org/)
* Прямой HTTP-запрос к сайту для анализа HTML
* SSL-проверка через stream_socket_client

= Возможности =

* Шорткод `[site_value_calculator]` (также `[website_value]` и `[site_estimator]`)
* AJAX-форма с анимированным прогресс-баром
* Rate limit: 5 запросов в минуту с одного IP
* Кэширование результатов (настраиваемое время)
* История всех оценок в БД + страница в админке
* Настройки: API key, базовая стоимость, валюта, таймаут
* Поддержка 5 валют: USD, EUR, RUB, UAH, KZT
* Тёмная тема (по prefers-color-scheme)
* Адаптивная вёрстка
* Поддержка мультиязычности (.pot файл)

== Installation ==

1. Загрузите папку `website-value-estimator` в `/wp-content/plugins/`.
2. Активируйте плагин в меню "Плагины" в WordPress.
3. Перейдите в "Настройки → Оценка сайтов" для конфигурации.
4. Создайте страницу и вставьте шорткод `[site_value_calculator]`.

== Frequently Asked Questions ==

= Нужен ли платный API-ключ? =

Нет. Google PageSpeed Insights API работает и без ключа (с ограничением по количеству запросов). Для активного использования рекомендуется получить бесплатный ключ в Google Cloud Console.

= Насколько точна оценка? =

Оценка является приблизительной и основана на публичных метриках. Реальная рыночная стоимость зависит от доходов сайта, трафика, бренда и других факторов, которые нельзя получить из публичных источников.

= Какие данные сохраняются? =

Если включена опция "Сохранять историю оценок", в БД сохраняются: URL, домен, стоимость, метрики, дата и IP-адрес запросившего. Это можно отключить в настройках.
