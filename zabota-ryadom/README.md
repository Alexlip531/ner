# WordPress тема «Забота рядом»

Тема для каталога услуг по уходу за пожилыми людьми: пансионаты, сиделки, уход на дому, реабилитация.

## Возможности

- 🎨 **Современный дизайн** в зелёно-бирюзовых тонах с акцентами
- 📱 **Полностью адаптивная** (mobile-first подход)
- 🏠 **Готовая главная страница** со всеми блоками:
  - Hero с табами (Пансионат / Сиделка / Уход на дому / Реабилитация)
  - Фильтр поиска (город + тип ухода + бюджет)
  - Социальное доказательство с аватарками
  - 4 плавающие карточки преимуществ
  - 5 карточек услуг (пансионаты, сиделки, реабилитация, уход на дому, спец. уход)
  - 8 иконок подбора по ситуации (инсульт, перелом, деменция и др.)
  - Калькулятор стоимости с ползунком бюджета
  - Карта с фильтрами и метками пансионатов
  - Каталог 4 пансионатов с рейтингами и тегами
  - Trust-bar с 4 преимуществами
  - Полноценный футер с контактами и соцсетями
- 🎯 **Кастомный логотип** через Customizer
- 📝 **2 меню**: главное и футер
- 🌐 **Готова к переводу** (.pot файл можно сгенерировать)
- ⚡ **Кастомные скрипты**: табы, слайдер бюджета, избранное, scroll-top
- 🎨 **CSS-переменные** для лёгкого перекрашивания
- 🌓 **Поддержка тёмной темы** через `prefers-color-scheme` (легко расширить)

## Установка

1. Скопируйте папку `zabota-ryadom/` в `/wp-content/themes/`
2. Активируйте тему в **Внешний вид → Темы**
3. Создайте страницу «Главная» и назначьте ей шаблон «Главная страница» (front-page.php подхватится автоматически, если в настройках чтения указать «статическая страница»)
4. Настройте меню в **Внешний вид → Меню**:
   - Пансионаты
   - Сиделки
   - Уход и услуги
   - Блог
   - О проекте
   - Контакты
5. Загрузите логотип в **Внешний вид → Свойства → Свой логотип**
6. Заполните контакты в **Внешний вид → Настроить → Контакты**

```text
├── style.css                 # Шапка темы (Theme Name и т.д.)
├── theme.json                # Глобальные настройки блоков и цветов
├── functions.php             # Подключение скриптов, регистрация меню
├── front-page.php            # Главная страница (все секции)
├── index.php                 # Блог/новости
├── page.php                  # Статическая страница
├── single.php                # Одна запись
├── search.php                # Результаты поиска
├── searchform.php            # Форма поиска
├── sidebar.php               # Боковая панель
├── comments.php              # Комментарии
├── 404.php                   # Страница 404
├── header.php                # Шапка (лого + навигация + действия)
├── footer.php                # Футер (trust-bar + колонки + low-bar)
├── inc/
│   └── customizer.php        # Настройки кастомайзера
├── template-parts/
│   ├── hero.php              # Hero-секция
│   ├── services.php          # 5 карточек услуг
│   ├── situations.php        # 8 иконок ситуаций
│   ├── calculator-map.php    # Калькулятор + карта
│   ├── catalog.php           # Каталог пансионатов
│   └── content-card.php      # Карточка записи блога
└── assets/
    ├── css/
    │   └── main.css          # Все стили темы (~1200 строк)
    ├── js/
    │   └── main.js           # Интерактив (табы, слайдер, избранное)
    └── img/                  # Изображения (placeholder)
```

## Цветовая палитра

| Код         | Hex       | Использование                |
|-------------|-----------|------------------------------|
| Primary     | `#10B981` | Основной зелёный (сердечки)  |
| Primary Dark| `#047857` | Кнопки, ссылки hover         |
| Primary Light| `#D1FAE5`| Фоны под зелёные элементы    |
| Secondary   | `#0F766E` | Trust-bar фон                |
| Footer Dark | `#134E4A` | Основной футер               |
| Accent      | `#F59E0B` | Звёзды рейтинга              |
| Text        | `#111827` | Основной текст               |
| Text Muted  | `#6B7280` | Вторичный текст              |
| Border      | `#E5E7EB` | Рамки                        |

Все цвета вынесены в CSS-переменные `:root` в начале `assets/css/main.css` — легко изменить под бренд.

## JavaScript-функции

- ✅ Мобильное меню (бургер)
- ✅ Переключение табов в hero
- ✅ Калькулятор бюджета с интерактивным ползунком и автопересчётом
- ✅ Избранное (клик по сердечку → заливка красным)
- ✅ Кнопка «Наверх» при скролле
- ✅ Плавное появление карточек при скролле (IntersectionObserver)
